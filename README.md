# GoToLmj

Proyek aplikasi Android berbasis Kotlin.

## Teknologi

- Kotlin
- Android SDK 36 (minSdk 24)
- AppCompat dengan tampilan edge-to-edge

## Status

Kerangka awal yang dibuat dari template Android Studio (satu `MainActivity`).
Fitur aplikasi belum dikembangkan di repositori ini; repo ini dipakai sebagai
titik awal pengembangan.

## Menjalankan

Buka folder proyek di Android Studio, tunggu Gradle sync selesai, lalu jalankan
pada emulator atau perangkat fisik (Android 7.0 ke atas).
